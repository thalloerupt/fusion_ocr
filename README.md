# fusion_ocr

一个面向侧端的ocr引擎，基于paddle系列模型

## 使用

首先请下载model,放在models/：

[PP-DocLayout_plus-L](https://modelscope.cn/models/PaddlePaddle/PP-DocLayout_plus-L_onnx)

[PP-FormulaNet_plus-S](https://modelscope.cn/models/Liyulingyue/PP-FormulaNet_plus-S-ONNX)

[PP-OCRv6_tiny_det](https://modelscope.cn/models/PaddlePaddle/PP-OCRv6_tiny_det_onnx)

[PP-OCRv6_tiny_rec](https://modelscope.cn/models/PaddlePaddle/PP-OCRv6_tiny_rec_onnx)
